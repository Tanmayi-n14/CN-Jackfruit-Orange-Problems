THE BASICS

You've used ping. You've never seen how it actually works.

When you type `ping google.com`, your computer sends a tiny message across the internet and waits for Google to say 'got it'. The time it takes to get a reply is called RTT — Round Trip Time. We built the exact same thing from scratch, using raw ICMP sockets — the same low-level protocol your operating system uses.

✉️

What is ICMP?

Internet Control Message Protocol. It's how computers on a network send error messages and operational info to each other. Ping is built on top of it.

🔌

Why Raw Sockets?

Normally your OS handles packets for you. Raw sockets let you build packets byte by byte — full control, full responsibility. That's why root/sudo is required.

⏱️

Round Trip Time

The milliseconds between sending a packet and receiving the reply. Lower = better connection. High RTT = something's slow between you and the destination.

⛓️‍💥

Packet Loss

When a packet you send never gets a reply. Could be congestion, a firewall blocking ICMP, or the host being down. Measured as a percentage.

The target sends back an Echo Reply.
We measure the time difference — that's your RTT.

Traceroute — What's the path?

[YOUR PC]
│ TTL=1
▼
[Router 1]
← 192.168.1.1 — 2.1ms
│ TTL=2
▼
[Router 2]
← 72.14.209.81 — 8.4ms
│ TTL=3
▼
[DESTINATION]
← 8.8.8.8 — 12.4ms ✓

We send packets with TTL=1. The first router hits zero, dies, and replies 'Time Exceeded' — revealing its IP.
We increment TTL each time, peeling back each hop until we reach the destination.
